Extract the ZIP and open `SheetPilot.html` in a current Chrome or Edge browser. It contains the application, fonts, calculation workers, and CSV/XLSX support; no installation, API key, or development server is needed. Browser or organization policy can restrict local HTML applications. For source installation, see the [project README](../README.md).

The portable edition passed the 20 acceptance workflows with networking disabled. The cloud browser blocks direct `file://` navigation, so those tests use the exact HTML contents through an intercepted loopback document and reject additional asset requests. See [standalone validation details](../docs/STANDALONE.md).

Select any task and click **Step-by-step guide** for a plain-language explanation, row/column selection instructions, input help and a worked example. All 301 tasks have guides. The AVERAGE guide includes an interactive practice worksheet for columns, rows and rectangular blocks. Each form input also includes **How to fill in…** instructions.
